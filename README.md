# Amazon-Sales
End-to-end Amazon sales analysis. A Power BI dashboard on 100K orders (2020–2024) tracks gross sales, revenue, payment methods, order status and category trends. A Python notebook cleans and explores ~129K Amazon India orders: revenue trends, top states and cities, cancellations and size demand.
# Amazon_sales_analysis

Amazon Sales Analysis | Data Analytics Project : Analyzed Amazon order data to identify sales trends, payment patterns and order status using Python, Excel and Power BI. Performed data cleaning, exploratory data analysis (EDA) using Python and built an interactive dashboard to generate actionable insights for data-driven decision-making.

## Overview

This project demonstrates an end-to-end Data Analytics workflow using Python and Power BI. The objective is to analyze Amazon sales data, identify business insights, and present findings through an interactive dashboard and a written report.

## Dataset

- Amazon Sales dataset (Amazon.in.xlsx): 100,000 orders, 20 columns, Jan 2020 to Dec 2024
- Contains order details, products, categories, payment methods, order status, customer, seller and location information
- Amazon India Sale Report (Mar to Jun 2022, ~129K orders) used for cleaning and EDA in Python
- Used for data cleaning, exploration and visualization

## Tools & Technologies

- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Power BI
- Excel
- Jupyter Notebook

## Project Steps

1. Load the dataset using Python.
2. Clean and preprocess the data.
3. Perform Exploratory Data Analysis (EDA).
4. Build an interactive Power BI dashboard.
5. Generate a project report.

## Dashboard

The Power BI dashboard provides:

- Key Performance Indicators (Gross Sales, Total Revenue, Total Orders, Total Quantity)
- Gross sales and units sold trend (2020 to 2024)
- Total orders by category and order status
- Gross sales by payment method
- State and seller map
- Interactive filters (month, category, state)

## Results

- Credit and debit cards account for about 55% of gross sales.
- About 75% of orders are delivered; cancelled and returned orders are about 3% each.
- Texas and California generate the most orders.
- In the India sales data, revenue fell 18.5% from April to June 2022, and Set and Kurta categories drive about 77% of revenue.
- Generated actionable business insights through data analysis.

## How to Run

1. Clone this repository.
2. Install the required Python libraries:
   pip install pandas numpy matplotlib seaborn openpyxl jupyter
3. Load the dataset into Jupyter Notebook.
4. Run the Python notebook for EDA and data cleaning.
5. Open the Power BI file to explore the dashboard.
6. Review the project report.
